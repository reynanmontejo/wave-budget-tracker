# Wave privacy statement

Wave is designed as an offline-first personal budget tracker. The app does not require an online account and does not upload financial records to a Wave server.

Financial data, preferences, planned activity, savings goals, and backup history are stored locally on the device. A user may explicitly export or share a JSON backup or CSV file through Android; the selected destination then controls that exported copy.

If app lock is enabled, the PIN verifier is stored using the device secure-storage service. Biometric checks are performed by the operating system, and Wave does not receive or store fingerprint or face data. Notification permission is used only for reminders configured for planned activity.

Removing the app or clearing its storage may permanently remove local data. Users should keep a recent backup outside the app's private folder. Wave currently has no cloud recovery service.
